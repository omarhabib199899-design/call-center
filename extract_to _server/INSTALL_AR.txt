تعيين أرقام واتساب للوكلاء — دليل التركيب
===========================================

تُستخرَج محتويات هذا الملف المضغوط داخل مجلد التطبيق مباشرة. المسارات
بداخله مضبوطة، فلا حاجة إلى نقل أي ملف يدويًا.


الخطوة الأولى — الرفع واستخراج الملفات
---------------------------------------
File Manager  ->  /home/hunaixon/whatscrm
Upload        ->  agent-numbers-update.zip
Extract       ->  /home/hunaixon/whatscrm

عند السؤال عن استبدال ملفات موجودة، وافق على الاستبدال (Overwrite).
الملفات التي ستُستبدل هي: server.js و app.js و helper/socket/index.js
و client/public/index.html، وهي تحتوي على التعديلات المطلوبة.

بعد الانتهاء، احذف الملف المضغوط من الخادم.


الخطوة الثانية — تطبيق جدول قاعدة البيانات
-------------------------------------------
phpMyAdmin  ->  اختر قاعدة البيانات  hunaixon_automation
Import      ->  اختر الملف:  database/agent_instances.sql
Go

ينشئ هذا الملف جدولًا باسم agent_instances، وتنفيذه أكثر من مرة آمن.


الخطوة الثالثة — إعادة تشغيل التطبيق
-------------------------------------
cPanel  ->  Setup Node.js App  ->  التطبيق  ->  Restart

لا حاجة إلى تنفيذ NPM Install، إذ لم تُضَف أي حزم جديدة.


الخطوة الرابعة — الاستخدام
---------------------------
افتح لوحة المستخدم:  https://automation.hunaix.online/user

ستجد زرًا أخضر أسفل يسار الشاشة مكتوبًا عليه:  Agent <-> Numbers
اضغط عليه، أو افتح الرابط مباشرة:

    https://automation.hunaix.online/agent-numbers.html

ستظهر قائمة الوكلاء وأمام كل وكيل أرقامك. حدِّد الأرقام التي تريد أن
يعمل عليها الوكيل، ثم اضغط حفظ.

ملاحظة: يلزم وجود وكلاء مُضافين مسبقًا من قسم Agents، وأرقام واتساب
مرتبطة من قسم WhatsApp QR.

بعد أي تغيير، على الوكيل تحديث الصفحة لتظهر لديه المحادثات الجديدة.


معالجة المشكلات
----------------
"Table agent_instances is missing"
    -> لم تُنفَّذ الخطوة الثانية. طبِّق ملف SQL.

الزر الأخضر لا يظهر
    -> حدِّث الصفحة تحديثًا كاملًا (Ctrl+Shift+R). يظهر الزر للمالك
       فقط وعلى صفحات /user، ولا يظهر للوكلاء ولا في لوحة المدير.

الوكيل لا يرى المحادثات
    -> تأكد من أنه حدَّث الصفحة، ومن أن الرقم محدَّد ومحفوظ.

الصفحة تطلب تسجيل الدخول
    -> هذا طبيعي. استخدم بيانات حساب المالك (نفس بيانات لوحة المستخدم).

-------------------

دون إشعار. التفاصيل الكاملة والشيفرة المطلوب إعادتها موجودة في ملف:
